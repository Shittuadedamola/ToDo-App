Todo App :

A simple, responsive Todo application built with HTML, Tailwind CSS, and JavaScript. This project helps users organize their daily tasks through a clean interface, with support for dark mode and persistent task storage.

FEATURES

Add Tasks: Create new tasks to keep track of your daily activities.

Mark as Completed: Check off completed tasks with a visual line-through effect.

Delete Tasks: Remove tasks you no longer need.

Dark Mode: Switch between light and dark themes.

Persistent Storage: Uses the browser's localStorage to save tasks and retain them after refreshing the page.

Responsive Design: Designed to provide a clean experience across different screen sizes.

TECHNOLOGIES USED

HTML5

Tailwind CSS

JavaScript (DOM Manipulation)

Browser Local Storage
